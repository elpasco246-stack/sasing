# Healthy Study Habits (sample course)

A small sample e-learning course in the style of an eXeLearning HTML5 export:
multi-page navigation, objectives, content blocks, collapsible text, multiple-choice
and true/false quizzes, and a reflection box. No build step, no dependencies.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub and upload all files in this folder
   (keep `index.html` at the top level).
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select
   `main` and `/ (root)`, then **Save**.
4. After a minute your course is live at
   `https://<your-username>.github.io/<repository-name>/`.

## Replace with your own eXeLearning course

Export from eXeLearning via **File > Download as > Website** (HTML5), unzip it, and
upload the contents to the repository root instead of these files.
